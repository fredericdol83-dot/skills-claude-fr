# redaction-administrative-dsfr

Pour les agents publics et les prestataires de l'administration. La skill cadre les écrits courants (notes de synthèse, comptes rendus, éléments de langage, mails) et la production de pages web avec le Design System de l'État (DSFR).

Elle rappelle que le logo Marianne et la police Marianne sont réservés aux services de l'État. Pour un autre projet, Claude utilise les composants DSFR sans le bloc-marque officiel.

Si votre service a sa propre charte, ajoutez-la dans le fichier : elle passera devant les règles générales.
