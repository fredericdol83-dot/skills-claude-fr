# studio-ebook-kdp

Une méthode complète pour créer un ebook, un livre papier ou un produit imprimable vendu sur Amazon KDP, avec uniquement des outils gratuits.

Les étapes : brief, recherche de niche notée sur 100, analyse des avis négatifs des concurrents, concept et plan, rédaction sans style IA, mise en page, couverture, relecture à l'aveugle par un sous-agent, métadonnées et lancement. Une section conformité rappelle la déclaration IA obligatoire chez KDP, les droits d'auteur et les sujets à éviter.

Claude s'arrête seulement à trois validations : le choix de la niche, le concept, le livre final.

Les règles KDP changent. Vérifiez les chiffres dans l'aide officielle avant de publier.
